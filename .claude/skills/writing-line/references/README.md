# References

Terminology, audience constraints, and exemplars that hold across all writing.

Starts near empty on purpose. It grows only when a draft exposes a gap, or when
the promotion hook surfaces a correction the user routes here.

One file per subject. Name it for the subject, not for the date.

Terms tied to one codebase or client belong in that repo instead, under
`.claude/writing-line/references/`. The skill reads this directory first and
the project one second, so a project term overrides a global term of the same
name.
